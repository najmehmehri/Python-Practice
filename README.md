# Algorithmic Problem Solving

A curated collection of solutions, optimizations, and analyses for algorithmic challenges from the Quera platform. This repository documents a disciplined, continuous journey in algorithmic thinking, data structures, and efficient software implementation.

---

## Problem-Solving Framework

For complex or multi-layered problems, a systematic 4-step framework is applied:
1. **Strip the Story:** Discard narrative overhead to extract core mathematical relations, bounds, and input/output contracts.
2. **Divide and Conquer:** Decompose the primary task into independent, manageable sub-problems.
3. **Manual Verification:** Trace logic and boundary cases on minimal hand-crafted test samples prior to coding.
4. **Pattern Recognition:** Map the structure onto canonical paradigms, including Disjoint Set Union (DSU), Breadth-First Search (BFS), Greedy heuristics, Dynamic Programming, and Shortest-Path algorithms.

---

## Technical Highlights

- **Algorithmic Coverage:** Solutions span graph theory, state-space exploration, combinatorial optimization, range-query structures, and text-based data analysis.
- **Performance Optimization:** Application of fast I/O via `sys.stdin.read` and vectorized operations with `NumPy` to meet tight time limits ($O(V^3)$ routines on dense inputs).
- **Runtime Safety:** Use of iterative path-compression routines to safeguard against Python recursion limits on deep structures.
- **AI-Assisted Development:** Artificial intelligence tools were utilized to help generate some of the code and optimize performance across several solutions in this repository.

## Repository Structure & Daily Routine

- **Commit Cadence:** Focused daily practice sessions (approximately 30 minutes per day).
- **Goal:** Building production-grade algorithmic literacy, mathematical modeling competence, and scalable coding habits.
